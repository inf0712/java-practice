## 📌 Learning Methodology

For every new topic:

1. Understand the concept and why it exists.
2. Study the syntax and execution flow.
3. Write small programs independently.
4. Solve progressively harder exercises.
5. Debug errors instead of immediately copying solutions.
6. Apply the concept in practical scenarios.
7. Revisit previous topics through mixed assignments.

### Practice Standards

- Avoid memorizing code without understanding it.
- Prefer writing programs independently.
- Understand why an error occurs and how to fix it.
- Practise combining multiple concepts.
- Focus on problem-solving rather than simply completing topics.
- Revisit older concepts regularly.
